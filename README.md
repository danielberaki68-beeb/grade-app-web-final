# Grade App Web

A fast Flask web version of Grade App.

## Run on Windows
1. Open PowerShell in this folder.
2. `python -m pip install -r requirements.txt`
3. `python app.py`
4. Open http://127.0.0.1:5000

Features:
- Dashboard
- Student management
- Search
- Custom grading limits
- School settings
- Student reports
- PDF reports
- AI placeholder ready for later remote AI integration

The AI connection is intentionally left separate so the web app can be tested first.
